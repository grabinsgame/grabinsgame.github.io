Welcome! This is a page dedicated to XP support.

Browsers

Are you tired of using IE 6? If yes, here are some alternatives. Click the names to download.

K-Meleon 1.5.4: This is a good browser. It supports HTTPS. It's basic and it's from 2010.

Opera 10.63: This is an ok browser. It doesnt support HTTPS. It's from 2010 as well. I think it also supports Windows 2000

RetroZilla 2.3: VERY similar to K-Meleon.

Programming, Modeling, and Game Development Tools

Mainly for me.

"CMD Here": Right click on a folder and you can open a CMD prompt!

Dev-C++ 4.9.9.2: A free IDE for C/C++ that I will be using for Grabins!

GLUT and GLFW: Libraries for OpenGL development.

Raylib (Custom Windows XP build): A build of raylib i made so it runs on windows xp. feel free to use for all your 2d and 3d games.

GIMP 2.2.10: A free image editor.

Blender 2.49b: An old version of Blender with OpenGL 1.x. make sure you export as FBX because if you don't, it will erase your model's skeleton... unless you use .dae

GTK+ 2.24.10: A runtime library that GIMP needs.

Audacity 1.2.6: A free audio editor.

Notepad++ 5.9: A free text editor.

7-Zip 9.20: A free file archiver.

Fragmosoft: A website with another 3d modeling tool and a 2d vector drawing thing.
